Compact gear, in a square frame

Redrawn 64×64 instead of 96×32, so compact things aren't stretched. Long things (the rifle, the sidearm, the kite drone, the slab deck) keep the wide frame. The stealth tool is now the ghost kit; the trauma kit gains the med gun. Pick a core build for each (others rarer, as with the drone) or vary them evenly.
