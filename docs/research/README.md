# Design research

What other games and designers have learned, kept so sessions can build on it instead of rediscovering it. One file per topic; add to a file rather than starting a near-duplicate. Each file ends with how the lessons apply to this game, and links to the proposal or decision they fed.

Decisions themselves live in the decision log (`docs/design/`); this folder is the background.
