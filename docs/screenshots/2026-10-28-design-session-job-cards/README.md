# Design session: job and side-work cards, 28 October (parked)

The owner felt the cards were all one grey, too wordy ("growth in driving"), and the bottom line was out of line, and asked whether the client was needed at a glance. Claude proposed three tiers (name and pay; what it takes; small details), the client as a quiet name with trust marks only when it matters (♥ trusted, ! wary), and side work's reward as one chip coloured by kind. Built into the real game (uncommitted) for these captures. **The owner wasn't convinced and kept the existing layout**; only the bottom-line alignment fix shipped. The proposal is kept as `drafts/prototypes/job-cards-proposal.patch` (applies to the 2026-10-28 code) for a later look.
