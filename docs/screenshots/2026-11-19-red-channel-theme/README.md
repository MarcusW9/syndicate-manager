# 2026-11-19 · Red channel theme

Design-session captures. The owner asked for variations of the current look (fonts, line weights, not layout), then for looks after Cyberpunk 2077's menus, then picked "K · Red channel" as a setting rather than a new skin.

The variant sheets were made by laying style-only CSS over the live game (seed 21, the same founders each time); none of A–J, L, M or N shipped.

1. `01-variants-phone-a-to-e.png`: phone (390 wide), Today, Jobs, Crew, Plan. A current, B hairline (Barlow Condensed, Inter, faint lines), C heavy frame (Oswald, 2px borders, 16px cuts), D terminal mono (IBM Plex Mono and Sans, dashed lines), E angular tech (Chakra Petch, corner brackets).
2. `02-variants-desktop-a-to-e.png`: the same five at 1440×900, Jobs and the plan.
3. `03-variants-desktop-f-to-j.png`: F side rails (Teko, a cyan rail instead of a box), G borderless (Space Grotesk and Space Mono, fills instead of lines), H CRT glow (Share Tech Mono, glow, heavy scanlines), I double line (Titillium Web, double hairline), J ruled sheet (Saira Condensed, top and bottom rules only).
4. `04-variants-desktop-cyberpunk-k-to-n.png`: A for comparison, K red channel (the one picked), L slot brackets, M amber planner, N comms HUD.
5. `05-red-phone-settings.png`: the shipped switch, Save › Look › Colours, with Red channel on.
6. `06`–`08`: the red channel on phone, Jobs, Today and Crew.
7. `09`–`10`: the red channel on desktop, Jobs and Crew.
