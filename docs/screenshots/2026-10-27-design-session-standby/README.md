# Design session: standby, 27 October

Captures from building squad-run slice 3 (Wheels and standby). A run is set up in Node to reach max alert with standby still at the van, loaded into slot 1 and played in the browser at 390×844, 2x, because the scripted set (`2026-10-27-wheels-and-standby`) doesn't reliably reach max alert.

| File | What it shows |
| --- | --- |
| `01-standby-call-in` | Max alert: the crew calls in with three options: call standby in (the alert stays up), go loud, or pull out. While a call-in is up the site plan scrolls with the page, so the choices have the screen |
| `02-standby-joins` | Standby (G) has run in from the van and joined the group; the feed card says the alert stayed up |
| `03-the-rest-of-the-run` | The rest of the run: an earlier save that missed, the target, and the way out |
