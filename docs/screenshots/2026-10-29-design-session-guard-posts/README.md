# Design session: guards on their posts (2026-10-29)

`node scripts/capture-fights.mjs 2026-10-29-design-session-guard-posts`: a loud Warehouse Lift run
with three rookies, built with the game's own core and loaded into the page.

dim and dashed, each with how many (2 at the fence, 3 and 3 inside, 3 in the yard office). 02-06 and
08-12: the fight at the fence plays out as in the slice 6b set, with the new guard numbers.
