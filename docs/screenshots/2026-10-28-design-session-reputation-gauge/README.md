# Design session: the reputation gauge, 28 October

The owner found the job board's reputation bar odd (it read as a big scale) and the (i) big and out of line. Five options were mocked at phone width (390×844, 2x); the owner chose **B** and asked to keep the rest for a later revisit. The mock is `drafts/prototypes/reputation-gauge-options.html`.

| File | What it shows |
| --- | --- |
| `01-five-options` | **A** ten red blocks (the 2026-10-27 version, tidied); **B** the Heat meter's small segmented track in cyan, chosen; **C** pips like the threat dots; **D** words only ("Reputation 2 · 8 more for new work"); **E** a hairline under the words |
| `02-chosen-b-on-the-board` | B on the job board from a test save at reputation 2.3, with the smaller (i) |
